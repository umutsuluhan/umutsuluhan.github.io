# umutsuluhan.github.io

Personal site of H. Umut Suluhan. Plain static HTML, CSS and JS with no build step.

- Preview locally: `python3 -m http.server` in this folder, then open http://localhost:8000
- Deploy: push to `main`. GitHub Pages serves the repo root.
- Custom domain later: add a `CNAME` file with the domain and set it in the repo's Pages settings. All links are relative, so nothing else changes.
